# Smart Assembly

Each Smart Assembly is a shared object on Sui, so the game and many players can use it at once. Owners can attach their own Move logic, called an extension, to change how it behaves.

Read more in the [EVE Frontier World Explainer](https://github.com/evefrontier/builder-documentation/blob/main/smart-contracts/eve-frontier-world-explainer.md).
