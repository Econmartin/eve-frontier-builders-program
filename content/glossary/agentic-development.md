# Agentic development

An agentic coding tool does more than suggest the next line. Given a task, it reads the project, makes changes across files, runs commands such as builds and tests, and reacts to what happens. You stay responsible for what it produces.

[Pillar 1](../1-agentic-and-low-code/README.md) covers how to use these tools for Frontier work.
