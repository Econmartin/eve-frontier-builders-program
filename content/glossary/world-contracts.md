# World Contracts

They're built in three layers: primitives for the world's digital physics, [Smart Assemblies](smart-assembly.md) built from those primitives, and player extensions that change how assemblies behave.

The source is in [evefrontier/world-contracts](https://github.com/evefrontier/world-contracts).
