# Low code

Low-code tools replace hand-written code with visual editors, templates and configuration. For the Frontier, they generate [Move](move.md) that extends a [Smart Assembly](smart-assembly.md), which you can read, build and later deploy.

See [Low code and Frontier Flow](../1-agentic-and-low-code/low-code-and-frontier-flow.md).
