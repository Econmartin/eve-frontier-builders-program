# EVE Token

The on-chain currency of EVE Frontier, a `Coin<EVEToken>` on [Sui](sui.md). An exchange service converts between EVE Token and the in-game [LUX](lux.md) currency in both directions.

Read more in [Introduction to EVE Vault](https://github.com/evefrontier/builder-documentation/blob/main/eve-vault/introduction-to-eve-vault.md).
