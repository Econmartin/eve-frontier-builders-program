# OwnerCap

Owner actions in the [World Contracts](world-contracts.md), such as bringing an assembly online, take an `OwnerCap` as proof of ownership. Code borrows the cap from your character, uses it, and must return it in the same transaction.

Read more in the [EVE Frontier World Explainer](https://github.com/evefrontier/builder-documentation/blob/main/smart-contracts/eve-frontier-world-explainer.md).
